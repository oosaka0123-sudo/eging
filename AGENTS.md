# Project Rules

This project follows `oosaka0123-sudo/ai-master`.

## Project-specific rules
- Production is Lolipop.
- PHP + MySQL is the primary runtime.
- Mobile First.
- CMS-managed gear data is the source for comparisons and simulator outputs.
- Do not hard-code affiliate rankings without explaining selection criteria.
- Product claims, specs, prices, stock and campaign information must be verifiable and date-aware.
- Keep secrets out of GitHub. Use `.env.example` only for variable names.
- Prefer small, dependency-light implementations.
- Simulator recommendations must show the rule/reason, not only a result.
- No fake reviews, fake test data, fake catches or invented field-test claims.
